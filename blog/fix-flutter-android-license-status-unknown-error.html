Fix: Flutter “Android License Status Unknown” Error — 2026 Step-by-Step Solution

The five fixes that solve this error, starting with the most common cause: missing Android command-line tools.

✍️ Deep Darji 📅 Published Oct 24, 2026 🔄 Updated Oct 24, 2026 ⏱ 4 min read 🏷 Flutter • Android • Errors

Seeing the Flutter "Android license status unknown" error when you run flutter doctor? You are not alone. It usually means Flutter cannot run the Android SDK's sdkmanager tool, because the command-line tools are missing, the SDK path is wrong, or Java is not found. Follow the fixes below in order.

This is one of the most common setup issues for beginners learning Flutter on Android Studio. New to the framework? Start with our guide on how to build a Flutter app in 2026.

Quick fix: Open Android Studio → SDK Manager → SDK Tools → install Android SDK Command-line Tools (latest) → run flutter doctor --android-licenses → type y to accept all → run flutter doctor again.

The Error Message

[!] Android toolchain - develop for Android devices
    ✗ Android license status unknown.
      Run `flutter doctor --android-licenses` to accept the SDK licenses.
      See https://flutter.dev/to/windows-android-setup for more details.

Related variants you may see: "cmdline-tools component is missing", "sdkmanager not found" and "Unable to find bundled Java version". The fixes below solve all of them.

Fix 1: Install Android SDK Command-line Tools

  1. Open Android Studio.
  2. Go to Settings → Languages & Frameworks → Android SDK → SDK Tools (or More Actions → SDK Manager on the welcome screen).
  3. Tick Android SDK Command-line Tools (latest).
  4. Click Apply and wait for the install.

This single step solves the problem for most people.

Fix 2: Accept the Android Licenses

flutter doctor --android-licenses

Press y and Enter for each prompt. Then check the result:

flutter doctor -v

Fix 3: Point Flutter to the Correct SDK Path

If Flutter looks in the wrong place, set the path yourself:

flutter config --android-sdk "C:\Users\YourName\AppData\Local\Android\Sdk"

Typical SDK locations:

OSDefault SDK path
WindowsC:\Users\<you>\AppData\Local\Android\Sdk
macOS~/Library/Android/sdk
Linux~/Android/Sdk

Fix 4: Fix Java ('Unable to find bundled Java version')

The license tool needs Java. Android Studio ships with its own JDK. Tell Flutter where it is:

flutter config --jdk-dir "C:\Program Files\Android\Android Studio\jbr"

On macOS the path is often inside /Applications/Android Studio.app/Contents/jbr/Contents/Home. Then run flutter doctor --android-licenses again.

Fix 5: Add Command-line Tools to PATH

Add this folder to your system PATH, then open a new terminal:

<SDK path>/cmdline-tools/latest/bin

Make sure the folder is named latest. If it has a version number or the tools sit directly in cmdline-tools, rename or reinstall via SDK Manager.

Still Not Working?

  • Run your terminal as Administrator (Windows) or check folder permissions.
  • Disable VPN or proxy that may block downloads.
  • Run flutter upgrade and flutter doctor -v, then read the verbose output carefully.
  • Reinstall the SDK Command-line Tools from SDK Manager.
  • Search your exact message in the official Flutter GitHub issues or watch a setup video on YouTube.

Frequently Asked Questions

Why does flutter doctor say Android license status unknown?

Flutter cannot run the Android SDK's sdkmanager, usually because command-line tools are missing, the SDK path is wrong or Java cannot be found.

How do I accept Android licenses in Flutter?

Run flutter doctor --android-licenses in a terminal and type y for each prompt.

What does 'cmdline-tools component is missing' mean?

The Android SDK Command-line Tools are not installed. Install them from Android Studio's SDK Manager under SDK Tools.

Do I need Android Studio to use Flutter?

You need the Android SDK. Android Studio is the easiest way to install it, though you can use VS Code as your editor.
